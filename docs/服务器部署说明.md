# 济南餐博会服务器部署

2026-11-11首次发布。

- 正式域名：https://csce.hm-d.cn
- 服务器：118.89.192.96，独立宝塔Nginx站点。
- 入口：/www/wwwroot/csce.hm-d.cn，指向独立时间戳发布目录。
- 发布目录：/www/wwwroot/csce.hm-d.cn-releases/20261111T072348Z
- 备份记录：/root/csce-backups/20261111T072348Z
- 配置：/www/server/panel/vhost/nginx/csce.hm-d.cn.conf
- HTTPS：系统Certbot签发，证书路径/etc/letsencrypt/live/csce.hm-d.cn/，首张证书有效期至2027-02-09。
- 验证目录：/www/wwwroot/csce-acme；certbot.timer已启用自动续期。
- 静态部署，不需要服务器运行Node.js；发布脚本scripts/deploy_server.py会打包dist、校验SHA256、备份原配置及入口、创建版本目录并切换符号链接。
- 首次部署前本站目录与配置均不存在。原济南旧站、沈阳及信展项目不覆盖；服务器现有其他四站配置哈希未改变。

## 更新

先运行npm ci、npm run typecheck、npm run build并预览，随后python scripts/deploy_server.py。
SSH密钥仅从用户目录.ssh/hm_ts_deploy_ed25519读取，不入库。

## 回滚

历史版本保留在csce.hm-d.cn-releases下。确认要回滚的绝对目录后，将csce.hm-d.cn入口原子切换至目标版本。涉及配置更改时恢复相应备份，先nginx -t再重载。

## 仓库

GitHub与Gitee仅同步源码和图片、文档，不提交dist、node_modules、research、凭据与临时压缩包。推送仓库不自动发布服务器。
